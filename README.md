# ETH MEXC Futures Trading Assistant Chip

**Description:**  
MEXC-এ ETH/USDT Perpetual Futures ট্রেড করার জন্য স্পেশালাইজড AI Chip। Real-time trend analysis, liquidity sweep detection, smart position sizing, এবং disciplined trade setup দেয়।

**Key Features:**
- Current Market Trend (Up/Down/Sideways)
- Previous Candle Liquidity Analysis  
- Smart Money Concepts (SMC) + Key Levels
- Accurate Position Size Calculator
- Risk Management & Trade Setup

**Best Use:**  
চার্টের অবস্থা বলো → Chip তোমাকে পুরো অ্যানালাইসিস + পজিশন সাইজ + এন্ট্রি/এসএল/টার্গেট দিবে।

**Example Prompts:**
- "এখন মার্কেট কেমন আছে?"
